# Regras Funcionais

- [ x ]O usuario vai poder criar uma nova transacao;
- [ x ]O usuario deve poder ter um resumo da sua conta;
- [ x ]O usuario deve poder listar todas as transacoes que ja ocorreram;
- [ x ]O usuario deve poder visualizar uma transacao unica;

# Regras de negócio

- [ x ]A transacao pode ser do tipo crédito que somará ao valor total, ou débito que irá subtrair do total;
- [ ]Deve ser possível identificar o usuario entre as requisicoes;
- [ ]O usuario só pode visualizar transacoes o qual ele criou.
